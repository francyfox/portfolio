**Stack:** TypeScript, Docker

An MCP (Model Context Protocol) server enabling AI agents to read and write Squidex CMS content directly. Provides 17 tools for schema and content management, supporting multiple Squidex instances through profile configuration. Works with any MCP-compliant client, including Claude Code and Cursor.
